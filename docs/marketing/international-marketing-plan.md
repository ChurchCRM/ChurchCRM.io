# ChurchCRM International Marketing Plan

## Purpose

Turn ChurchCRM's existing international and localization strength into a focused acquisition strategy without assuming that every language or country deserves equal marketing investment.

## Strategic premise

ChurchCRM's international advantage is more than translation.

The application supports translated interfaces and regional localization, including date/time, phone, timezone, currency, and other locale-sensitive presentation. This makes ChurchCRM relevant to churches that may be poorly served by products designed primarily around one market.

The website currently supports a smaller set of languages than the application. That gap is an opportunity, but translating everything indiscriminately is not the strategy.

## Principles

- Language and country are separate dimensions.
- Localization is more important than a language-count headline.
- Prioritize markets by adoption potential, not population alone.
- Use current product capability as the foundation.
- Measure success by downloads/installs, not follower counts.
- Localized content should preserve the same ChurchCRM positioning and product truth.
- Localized marketing should sound natural to the target community, not machine-translated.

## Current website language footprint

The current Hugo site is configured for:

- English
- Spanish
- Portuguese
- Chinese
- French
- Russian
- German
- Arabic

The application/documentation language footprint is broader. The exact current count should be verified from the application before being used in public copy.

## Opportunity matrix

Build and maintain a matrix with these dimensions:

| Dimension | Example question |
|---|---|
| Language | Is the interface/content available? |
| Country | Which countries plausibly need the product? |
| Existing users | Do we already have evidence of adoption? |
| Website localization | Does a localized landing experience exist? |
| CRM localization | Is the application sufficiently localized? |
| Search demand | Are churches searching for relevant solutions? |
| Competition | Are mainstream products strong/weak in the market? |
| Affordability | Is price sensitivity likely to matter? |
| Self-hosting fit | Is ownership/deployment a meaningful advantage? |
| Community | Are contributors/translators/partners available? |
| Adoption potential | Can the market plausibly produce installs? |
| Social priority | Is there a useful channel/community to reach? |

## Priority scoring

A practical score can combine:

- existing adoption evidence
- product localization readiness
- website readiness
- search/discovery opportunity
- competitive gap
- affordability fit
- self-hosting fit
- community reach
- expected installation potential

The model should be transparent enough that a contributor can challenge the assumptions.

## Language strategy

Do not require every English campaign to be translated into every supported language.

Instead:

1. Identify the audience and problem.
2. Identify countries/languages with meaningful opportunity.
3. Check product and website readiness.
4. Localize the content that has a realistic path to adoption.
5. Use local examples and terminology where appropriate.
6. Measure installations/downloads.
7. Increase or decrease investment based on evidence.

## Country strategy

A language can represent many different markets.

For example:

- Spanish should be considered across multiple countries and US Hispanic audiences.
- Portuguese should not be treated as Brazil-only.
- English should not be treated as US-only.
- Arabic should be evaluated across relevant regions rather than as a single homogeneous audience.

Country targeting should account for church structures, hosting norms, payment/giving practices, internet access, local terminology, and competing software.

## Localized messaging

The core story should remain consistent:

> Church management software you can actually start with.

Then adapt the proof:

- localized experience
- ownership/self-hosting
- affordability
- practical church workflows
- community/open source

Do not translate slogans literally when a culturally natural expression communicates the same idea better.

## Localized visuals

The future Playwright Visual Media Pipeline should be able to generate selected localized screenshots with:

- translated interface
- regional date formatting
- regional currency formatting
- timezone context
- RTL layout where applicable

Use localized visuals only when they improve comprehension or trust.

## Social strategy

Social channels should be selected by actual community presence.

Potential channels include:

- LinkedIn
- Facebook
- Instagram
- X
- Reddit
- YouTube
- local church technology communities
- regional church forums or partner communities

Do not create a social account for every country simply because the language is supported.

## Community-led international growth

International growth should invite participation:

- translators
- church administrators
- regional users
- documentation contributors
- testers
- developers
- community ambassadors

A useful message is:

> ChurchCRM is open source. If your church or country needs something we are missing, help us make it better.

## Attribution

All campaign links to ChurchCRM-owned pages should use the standard UTM vocabulary in the Attribution & Adoption Measurement document.

Country/language campaigns should use campaign/content values that allow performance to be compared without creating inconsistent naming.

## Success metrics

Primary:

- downloads/installations by market where measurable

Secondary:

- qualified visits to localized pages
- demo starts
- install-page visits
- GitHub outbound clicks
- Softaculous outbound clicks
- community/contributor activity

Diagnostic:

- reach
- engagement
- followers
- comments

Do not declare a market successful because it generated likes if it produces no meaningful installation activity.

## Rollout model

### Phase 1 — Measure

Create the opportunity matrix and identify current adoption evidence by language/country.

### Phase 2 — Prepare

Ensure product truth, website localization, installation information, visuals, and UTM tracking are ready for priority markets.

### Phase 3 — Pilot

Run focused campaigns in a small number of high-potential markets.

### Phase 4 — Learn

Compare adoption outcomes and community feedback.

### Phase 5 — Expand

Invest further in markets that demonstrate a credible path to adoption and community sustainability.

## Guardrails

Do not:

- claim a language is fully localized without verifying it
- equate language support with country readiness
- publish machine-translated marketing without review when quality matters
- imply ChurchCRM has local payment integrations that have not been verified
- invent country-specific customers or adoption numbers
- optimize for follower count instead of installation

## Long-term opportunity

The strongest international position is not “we have many translations.” It is:

> **Churches around the world can use an open system that respects their language, locale, budget, and need for ownership.**

That is a product and community story, not merely an SEO tactic.
