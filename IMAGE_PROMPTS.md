# ChurchCRM 7.1 — Image Prompts for Blog & Social Media

All prompts follow a consistent style direction:
**Modern flat illustration + soft gradient background + warm church community feel.**
Avoid: stock-photo clichés, crossed hands, generic handshakes, clip-art churches.

Suggested tools: Midjourney v7, DALL-E 3, Adobe Firefly, Flux Dev.
Aspect ratios: `16:9` for blog headers, `1:1` for LinkedIn feed posts, `4:5` for LinkedIn portrait posts.

---

## Style reference (use this as a prefix for any prompt)

> "Flat vector illustration, modern SaaS product aesthetic, soft pastel gradient background in indigo and teal, clean sans-serif UI elements, warm and welcoming community feel, professional but approachable, no people clipart, no stock photo faces, bold typography accents, generous whitespace"

Prefix it to any prompt below or use them standalone.

## Usage notes

- **Midjourney:** Append `--ar 16:9` or `--ar 1:1` and `--style raw --v 7`
- **DALL-E 3:** Use as-is; add "Do not include any real logos or trademarked symbols" to avoid copyright flags
- **Adobe Firefly:** Add "Content credentials included" for licensed commercial use
- **Flux Dev:** Works best with shorter prompts — use the core concept sentence from each + the style reference prefix
- **Consistency tip:** Generate all images in one session with the same style reference prefix to maintain visual coherence across the post series
